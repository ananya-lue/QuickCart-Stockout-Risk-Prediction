# QuickCart Stockout Risk Prediction

## Project Overview
This project focuses on predicting the risk of inventory stockouts using machine learning techniques.

## Objectives
- Analyze inventory and product data
- Identify factors contributing to stockouts
- Build classification models to predict stockout risk
- Compare model performance
- Provide business recommendations

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Models Used
- Logistic Regression
- Random Forest Classifier

## Business Recommendations
- Monitor high-risk products regularly
- Maintain appropriate safety stock
- Improve supplier reliability monitoring
- Prepare inventory before high-demand events
- Use the prediction model for early stockout alerts
